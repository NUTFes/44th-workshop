## 使い方

### 画像→粒子変換

`white-background-removal-color-cast.jpg` を花火画像として読み込み、白背景由来の迷子のパーティクルが表示されないことを確認します。淡い色と濃い色の花火が残ることも確認します。

### PDF・キーホルダー印刷

管理画面から画像を登録し、「PDFの生成」と「キーホルダーの印刷」をそれぞれ実行します。出力された花火画像の背景が透明で、色付きの図形だけが印刷対象になっていることを確認します。

## 画像の由来

`white-background-removal-color-cast.jpg` はOpenAIの組み込みImageGenでテスト専用に生成した画像を、JPEG品質78へ変換したものです。外部サイトから取得した画像ではありません。
